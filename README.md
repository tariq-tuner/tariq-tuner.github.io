# Tariq Tuner

موقع ثابت لشروحات برمجة وتشخيص السيارات، منشور عبر GitHub Pages:
https://tariq-tuner.github.io/

## الملفات

- `index.html`: الرئيسية والأقسام. الأقسام التي لم تُجهز بعد موضحة بعبارة «قريبًا».
- `gm.html`: يعرض تلقائيًا العناصر التي تحمل `type: "guides"` و`brand: "GM"` من `data/posts.json`.
- `post.html?id=…`: يعرض الموضوع الكامل بحسب `id`، سواء كان رقمًا أو نصًا فريدًا.
- `js/posts.js`: قراءة البيانات والتحقق منها وعرض النصوص والصور والروابط بأمان.
- `js/gm.js` و`js/post.js`: عرض القائمة وتفاصيل الموضوع.
- `admin/index.html` و`admin/add.html`: لوحة الإدارة وتجهيز بيانات المواضيع.
- `images/`: صور المواضيع. الشعار الحالي في `IMG_0035.png` بجذر الموقع.

## إضافة موضوع

1. ارفع الصورة من لوحة التحكم إلى مجلد `images` مع مراعاة اسم الملف وحالة الأحرف.
2. افتح `admin/add.html` وأدخل العنوان والشرح وبقية الحقول. مثال مسار الصورة: `images/IMG_4750.png`.
3. اضغط «تجهيز الموضوع» ثم «نسخ بيانات الموضوع».
4. افتح ملف المواضيع وأضف الكائن الجديد داخل مصفوفة `data/posts.json`، مع فاصلة بين العناصر، دون استبدال المواضيع الموجودة. يجب أن يكون كل `id` فريدًا وأن يحتوي كل موضوع على عنوان.
5. احفظ التعديل في GitHub وانتظر اكتمال إجراء **pages build and deployment**، ثم جرّب البطاقة ورابط الموضوع والصورة.

يبقى الحفظ والرفع عبر حساب GitHub وصلاحيات المستودع. لوحة الإدارة صفحة ثابتة لتجهيز البيانات، ولا تحفظها تلقائيًا في المستودع. لا تُضف رموز وصول أو كلمات مرور إلى ملفات الموقع أو حقول المواضيع.

المحتوى نص عادي مع الحفاظ على فواصل الأسطر؛ لا يُنفذ HTML داخل المواضيع. الروابط الخارجية اختيارية وتقبل HTTP وHTTPS فقط. الصور تقبل مسارًا محليًا أو رابط HTTP/HTTPS.

## المعاينة والتحقق

شغّل الموقع عبر خادم HTTP محلي، وليس بفتح الملفات بصيغة `file://`، لأن الصفحات تقرأ JSON عبر `fetch`.
تحقق من الرئيسية ثم GM ثم «اقرأ الموضوع»، ومن صورة الموضوع والرجوع إلى القائمة. جرّب أيضًا `post.html` دون معرف ومع معرف غير موجود، وتحقق من نموذج الإضافة والنسخ وعرض الهاتف.
